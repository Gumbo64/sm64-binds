This is a collection of interfaces for Mario 64 in rust, python and javascript, all using wasmtime. They require a US z64 copy of the ROM (8.00MB large).
To avoid copyright problems, an XOR'd version of the WASM is distributed, which can must be combined with the ROM to get the proper WASM.

Rust (most maintained)
https://crates.io/crates/sm64-binds/1.0.24

Python
